# Netflix Content Analytics Dashboard

I built this Power BI dashboard to explore Netflix’s catalog. It shows how movies and TV shows are distributed by type, release year, rating, country, and genre.

## Highlights
- Clear split between Movies and TV Shows
- Ratings breakdown (TV-MA, TV-14, PG, etc.)
- Trend of content added over the years
- Country‑wise distribution
- Genre insights with treemap

## How to View
Download the `.pbix` file from this repo and open it in Power BI Desktop to explore the visuals interactively.
